SERVO MOTOR FAMILIES
─────────────────────
1. Micro Servo (SG90, MG90S)
   - Body: 22.5×12×29 mm, mounting tabs 32.2×12 mm with M2 holes 28 mm apart
   - Output spline: ø4.8 mm, 25T, shaft protrudes 12 mm

2. Standard Servo (MG996R, MG995, DS3218)
   - Body: 40×20×43.5 mm, mounting tabs 54×20 mm with M3 holes 49 mm apart
   - Output spline: ø6.0 mm, 25T, shaft protrudes 15 mm
   - Torque: 9.4–10 kg·cm (MG996R at 4.8V)

3. Large Servo (DS3120, Hitec HS-755HB)
   - Body: 66×30×56 mm, mounting tab span ≈ 75 mm, M4 mounting
   - High torque: 15–20 kg·cm

4. Digital Servo / Robot Servo (Dynamixel XL-430)
   - Body: 28×46×34 mm, ø4 mm through-shaft, daisy-chainable
   - Serial bus (TTL/RS485); position feedback

KEY PARAMETERS
──────────────
  servo_body_length      — e.g. 22.5 mm SG90, 40 mm MG996R
  servo_body_width       — e.g. 12 mm, 20 mm
  servo_body_height      — e.g. 29 mm, 43.5 mm
  servo_tab_span         — distance between mounting hole centres (28 mm SG90, 49 mm MG996R)
  servo_tab_width        — overall tab width including body
  servo_mount_hole_d     — M2 for SG90, M3 for MG996R
  servo_shaft_od         — ø4.8 mm SG90, ø6.0 mm MG996R
  servo_shaft_height     — distance from mounting face to shaft tip
  servo_flange_clearance — 0.5–1.0 mm gap around servo body
  horn_od                — output horn outer diameter
  horn_arm_length        — lever arm length for force calculation
  bracket_thickness      — 3–4 mm FDM for standard servos
  pivot_clearance        — 0.3–0.5 mm between rotating and static parts

ROBOT ARM JOINT — MG996R U-BRACKET (CORRECT WING DESIGN)
──────────────────────────────────────────────────────────
  Wings at x = ±tab_span/2 hold the servo mounting tabs.
  Holes through wings are along X axis (rotate([0,90,0])).
  No servo body pocket needed — servo slides into the open top of the U.

  $fn = 64;
  servo_l      = 40.5;  servo_w = 20.5;  servo_h = 44.0;
  tab_span     = 49.0;  // MG996R hole-to-hole distance along X
  hole_d       = 3.8;   // M3 + FDM clearance
  bracket_t    = 4.0;
  tab_hole_z   = 9.5;   // MG996R: mounting hole height above servo body base
  cable_hole_d = 6.0;
  wing_w  = servo_w + 2 * bracket_t;  // 28.5 mm
  wing_h  = servo_h + bracket_t;      // 48 mm
  plate_l = tab_span + bracket_t;     // 53 mm

  module mg996r_u_bracket() {
    difference() {
      union() {
        // Base plate (bottom of U)
        translate([0, 0, bracket_t / 2])
          cube([plate_l, wing_w, bracket_t], center = true);
        // Left wing — centered on tab hole x-position
        translate([-(tab_span / 2), 0, bracket_t + wing_h / 2])
          cube([bracket_t, wing_w, wing_h], center = true);
        // Right wing
        translate([ (tab_span / 2), 0, bracket_t + wing_h / 2])
          cube([bracket_t, wing_w, wing_h], center = true);
      }
      // Tab holes through wings along X (NOT vertical Z cylinders)
      for (x = [-tab_span / 2, tab_span / 2])
        translate([x, 0, bracket_t + tab_hole_z])
          rotate([0, 90, 0])
            cylinder(h = bracket_t + 2, d = hole_d, center = true, $fn = 32);
      // Cable relief hole in base plate
      translate([0, 0, bracket_t / 2])
        cylinder(h = bracket_t + 2, d = cable_hole_d, center = true, $fn = 32);
      // Base mounting holes — 2x2 pattern
      for (xi = [-(plate_l/2 - 6), plate_l/2 - 6])
        for (yi = [-(wing_w/2 - 6), wing_w/2 - 6])
          translate([xi, yi, bracket_t / 2])
            cylinder(h = bracket_t + 2, d = 3.8, center = true, $fn = 32);
    }
  }

  COMMON FAILURES TO AVOID:
  - Do NOT drill tab holes as vertical Z cylinders through base plate.
  - Do NOT place wings along Y axis (front/back of servo body).
  - Do NOT center a servo pocket cube at z=0 — it destroys the base plate.

DESIGN RULES
────────────
  - Servo mounting tabs: print holes 0.1 mm undersized and drill/tap to thread M2/M3
  - Rotating joint: shaft bore + 0.3–0.5 mm for loose rotation; bushing bore + 0.1 mm
  - Horn screw: always use the supplied servo screw through centre hole into spline shaft
  - Servo saver: spring-loaded horn absorbs shock; use for direct-drive steering
  - For arms: print links flat (layers perpendicular to bending moment) for max strength
  - Cable routing: add ø5 mm holes along arm length to route servo wires cleanly

OPENSCAD CODE INTERPRETATION
Mechanical meaning to code:
- Servo parts include horn, bracket, arm, linkage point, cable relief, and mounting ears.
- Arms, horn disks, ribs, and brackets are solid material in union().
- Servo spline/bore, mounting holes, linkage holes, and wire channels are removed material in difference().
- Servo horns are radial arms or disks centered on the servo output axis.
- Linkage holes repeat along an arm at known radius positions.
- Servo brackets need rectangular servo body clearance and side mounting holes.
- Cable routing is a small channel or hole subtracted from the arm/bracket.
- Keep arm thickness and rib height as parameters for strength tuning.

OPENSCAD CODE RULE IMPLEMENTATIONS
Use these patterns to turn robotics-servo rules into OpenSCAD.

Rule: servo horn center attaches to spline/output shaft.
OpenSCAD action:
  difference() {
    cylinder(h=horn_thickness, d=hub_diameter, center=true, $fn=96);
    cylinder(h=horn_thickness+2, d=spline_bore_diameter, center=true, $fn=64);
  }

Rule: servo arm is a radial beam from the hub.
OpenSCAD action:
  translate([arm_length/2,0,0]) cube([arm_length, arm_width, horn_thickness], center=true);

Rule: linkage holes repeat along arm radius.
OpenSCAD action:
  for (r=[hole_pitch:hole_pitch:arm_length])
    translate([r,0,0]) cylinder(h=horn_thickness+2, d=linkage_hole_diameter, center=true, $fn=32);

Rule: MG996R U-bracket — wings at ±tab_span/2 hold the servo tabs; no pocket needed.
OpenSCAD action:
  // Two wing plates, each centered at x = ±tab_span/2:
  translate([-(tab_span/2), 0, bracket_t + wing_h/2]) cube([bracket_t, wing_w, wing_h], center=true);
  translate([ (tab_span/2), 0, bracket_t + wing_h/2]) cube([bracket_t, wing_w, wing_h], center=true);
  // Tab holes through wings along X axis:
  for (x = [-tab_span/2, tab_span/2])
    translate([x, 0, bracket_t + tab_hole_z]) rotate([0,90,0])
      cylinder(h=bracket_t+2, d=hole_d, center=true, $fn=32);

Rule: cable relief is a small channel through bracket wall.
OpenSCAD action:
  translate([cable_x, bracket_wall_y, cable_z]) cube([cable_width, wall_thickness+2, cable_height], center=true);

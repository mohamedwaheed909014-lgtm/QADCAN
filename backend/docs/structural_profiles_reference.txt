I / H / WIDE-FLANGE BEAM FAMILY DIFFERENCES
───────────────────────────────────────────
Do not treat every I-shaped section as one generic profile. Pick the variant
from the user wording and preserve its proportions.

1. Standard I-beam / American S-shape / classic I-section
   - Keywords: standard I-beam, S-beam, classic I beam, tapered flange.
   - Flanges are relatively narrow and have a visible inward taper/slope.
   - Typical proportion: flange_width is about 0.45 to 0.65 * beam_height.
   - Model with top and bottom flanges plus web; if possible use tapered
     flange polygons or hull() blocks so the flange is thicker near the web.
   - This is not a wide H beam.

2. Narrow-flange I-beam / narrow I-section / IPE-like beam
   - Keywords: narrow flange, narrow I beam, IPE beam, slim I section.
   - Flanges are flat/parallel, not tapered, and narrower than the height.
   - Typical proportion: flange_width is about 0.40 to 0.60 * beam_height.
   - Web is tall and slender; flange_thickness and web_thickness are modest.
   - Model as three rectangular prisms: top flange, bottom flange, web.

3. Wide-flange H-beam / W-beam / HEA / HEB
   - Keywords: wide flange, H-beam, H beam, W beam, HEA, HEB, universal column.
   - Flanges are flat/parallel and wide; section visually reads as H.
   - Typical proportion: flange_width is about 0.80 to 1.20 * beam_height.
   - Use wider/thicker flanges and a central web; H-beams often have flange
     width close to beam depth.
   - Model as three rectangular prisms with flange_width much larger than the
     narrow-flange/IPE case.

Variant selection rules:
- If user says "standard I-beam", "classic I-beam", or "S beam", use tapered flanges.
- If user says "narrow flange", "IPE", or "slim I beam", use narrow flat flanges.
- If user says "wide flange", "H beam", "W beam", "HEA", or "HEB", use wide flat flanges.
- Always expose beam_height, flange_width, flange_thickness, web_thickness, and beam_length as parameters.
- Never output a single rectangular bar for any of these variants.

OPENSCAD EXTRUSION PROFILES (linear_extrude from 2D cross-section)
────────────────────────────────────────────────────────────────────
  module angle_section(leg, thickness, length) {
    linear_extrude(height=length)
      difference() {
        square([leg, leg]);
        translate([thickness, thickness]) square([leg, leg]);
      }
  }

  module rhs_section(width, height, wall, length) {
    linear_extrude(height=length)
      difference() {
        square([width, height], center=true);
        square([width-2*wall, height-2*wall], center=true);
      }
  }

  module chs_section(od, wall, length) {
    linear_extrude(height=length)
      difference() {
        circle(d=od, $fn=64);
        circle(d=od - 2*wall, $fn=64);
      }
  }

DESIGN RULES
────────────
  - Always model with extrusion OD dimensions + 0.1–0.2 mm clearance for slide-fit brackets
  - T-slot hardware: 2020 → M5, 2040 → M5, 4040 → M8 (check manufacturer spec)
  - Corner brackets should engage ≥ 2 T-nuts per rail for rigid connection
  - Pre-assembly: loose brackets, align square with machinist square, tighten in sequence
  - Torsional stiffness: add diagonal braces or gusset plates for large frames
  - Printed end caps: 0.2 mm undersize on each inserted dimension for press fit

OPENSCAD CODE INTERPRETATION
Mechanical meaning to code:
- Structural profiles are beams with constant cross-sections extruded along length.
- Beam solids, brackets, gussets, plates, and end caps are solid material in union().
- Slots, bolt holes, T-slots, lightening holes, and end bores are removed material in difference().
- Use cube() for rectangular extrusions and subtract long slot cubes/cylinders to represent T-slots.
- Gusset plates are triangular or rectangular supports between beams.
- Bolt holes through brackets should align with profile slots or known hole spacing.
- Frames are assemblies of translated/rotated profile modules.
- Keep beam length, profile_size, slot_width, and wall_thickness as parameters.

OPENSCAD CODE RULE IMPLEMENTATIONS
Use these patterns to turn structural-profile rules into OpenSCAD.

Rule: profile beam is a long rectangular extrusion.
OpenSCAD action:
  cube([profile_length, profile_size, profile_size], center=true);

Rule: T-slot is a long subtracted channel.
OpenSCAD action:
  translate([0,profile_size/2,0]) cube([profile_length+2, slot_width, slot_depth], center=true);

Rule: hollow extrusion removes inner core.
OpenSCAD action:
  cube([profile_length+2, profile_size-2*wall_thickness, profile_size-2*wall_thickness], center=true);

Rule: corner bracket plate uses holes matching slot spacing.
OpenSCAD action:
  for (x=[-hole_spacing/2,hole_spacing/2])
    translate([x,0,0]) cylinder(h=plate_thickness+2, d=bolt_hole_diameter, center=true, $fn=48);

Rule: diagonal brace is a rotated beam between frame members.
OpenSCAD action:
  rotate([0,0,brace_angle]) cube([brace_length, brace_width, brace_thickness], center=true);

CURATED MODELING-GAP CORRECTION: I-BEAM MUST NOT BE A RECTANGULAR BAR
Source baseline: research paper failure case where an I-beam prompt was answered with a plain rectangular beam.
Use this whenever the prompt mentions I-beam, I section, H-beam, steel beam, flange, web, IPE, or HEA profile.

Real mechanical interpretation:
- An I-beam has two horizontal flanges and one vertical web.
- The flanges resist bending because they are far from the neutral axis.
- The web carries shear and spaces the flanges apart.
- A single cube with full beam height and flange width is a rectangular bar, not an I-beam.

OpenSCAD action:
```scad
$fn = 96;

beam_length = 180;
beam_height = 60;
flange_width = 36;
flange_thickness = 8;
web_thickness = 7;

module i_beam_profile() {
  union() {
    translate([0, 0, beam_height/2 - flange_thickness/2])
      cube([beam_length, flange_width, flange_thickness], center=true);
    translate([0, 0, -beam_height/2 + flange_thickness/2])
      cube([beam_length, flange_width, flange_thickness], center=true);
    cube([beam_length, web_thickness, beam_height - 2*flange_thickness], center=true);
  }
}

i_beam_profile();
```

If holes are requested, subtract them after the flange/web union:
```scad
difference() {
  i_beam_profile();
  for (x=[-60,0,60])
    translate([x,0,0])
      rotate([90,0,0])
        cylinder(h=web_thickness+2, d=8, center=true, $fn=48);
}
```

TRUSS FAMILY REFERENCE: REAL-WORLD STRUCTURAL TRUSSES
Use this whenever the prompt mentions truss, roof truss, bridge truss, king post,
queen post, Pratt, Howe, Warren, Fink, K-truss, top chord, bottom chord, diagonal
web, vertical web, or gusset plate.

Core modeling assumption:
- A truss is an assembly of straight members connected at nodes, not a filled
  decorative triangle.
- Each member should be modeled between two endpoint nodes using length and angle.
- Realistic generated code should include bottom chord, top chord or rafters, web
  members, gusset plates, bolt holes, and support pads.

Main parameters:
- span: horizontal support-to-support distance.
- rise: roof-truss height from bottom chord to apex.
- depth: bridge-truss distance between top and bottom chords.
- panel_count: number of bays along the span.
- truss_width: out-of-plane thickness or side-truss spacing.
- member_width and member_depth: chord/web member section dimensions.
- gusset_radius, gusset_thickness, bolt_diameter: node connection details.
- support_pad_length and support_pad_width: bearing footprint at supports.

Derived parameters and formulas:
- panel_length = span / panel_count
- roof_pitch_angle = atan(rise / (span/2))
- rafter_length = sqrt((span/2)^2 + rise^2)
- queen_post_x = span/4 from each support for symmetric queen-post truss
- truss_depth = span/8 to span/12 for simple bridge trusses
- diagonal_length = sqrt(panel_length^2 + truss_depth^2)
- gusset_plate_width = 2.5 * member_width
- bolt_edge_distance >= 1.5 * bolt_diameter
- slenderness_ratio = member_length / radius_of_gyration

Materials:
- Structural steel S235/S275/A36 for welded or bolted bridge, roof, and plant frames.
- RHS/SHS hollow steel tube for clean welded trusses with torsional stiffness.
- 6061-T6 or 6082-T6 aluminum for lightweight display rigs and removable frames.
- Glulam or C24 timber for roof trusses and architectural spans.
- PLA/PETG/PA-CF for scale models and non-load-bearing prototypes only.

Common truss features:
- Top chord / rafters: upper compression or bending-edge members.
- Bottom chord / tie beam: lower tension member connecting supports.
- Web members: diagonals and verticals that subdivide the span into panels.
- Panel points: nodes where chords and webs meet.
- Gusset plates: bolted or welded connector plates at nodes.
- Bolt holes: connection detail through gusset plates and support pads.
- Support pads / bearing plates: load transfer blocks at left and right supports.

Main parameters:
- span, rise or depth, panel_count, truss_type, member_width, member_depth,
  truss_width.

Non-main parameters:
- gusset_radius, gusset_thickness, bolt_diameter, support_pad_length,
  support_pad_width, edge_distance, member_clearance, node_plate_offset.

Shared derived formulas:
- panel_length = span / panel_count
- support_reaction_points = +/- span/2
- roof_pitch_angle = atan(rise / (span/2))
- rafter_length = sqrt((span/2)^2 + rise^2)
- bridge_diagonal_length = sqrt(panel_length^2 + depth^2)
- warren_diagonal_angle = atan(depth / panel_length)
- pratt_howe_diagonal_angle = atan(depth / panel_length)
- gusset_plate_width = 2.5 * member_width
- gusset_thickness = 0.25 to 0.40 * member_width for visual CAD
- minimum_bolt_edge_distance = 1.5 * bolt_diameter

Common truss types and usage:
- King-post truss: two rafters, one central vertical king post, bottom tie beam,
  and two angled struts from the bottom-center joint to midpoint nodes on the
  rafters; short roof spans, sheds, porches. Split each rafter at the strut node
  so the visible joints are left support -> left strut node -> apex -> right
  strut node -> right support. Do not add a horizontal straining beam or collar
  beam unless explicitly requested.
- Queen-post truss: two vertical queen posts, bottom tie beam, rafters that pass
  through the queen-post top nodes to the apex, and a horizontal straining beam
  between the queen-post tops; medium roof spans and halls. Do not add diagonal
  internal braces unless explicitly requested.
- Pratt truss: verticals plus diagonals sloping toward the span center; steel bridge
  and roof trusses.
- Howe truss: verticals plus diagonals sloping away from span center; traditional
  timber bridges and roof structures.
- Warren truss: alternating triangular webs; bridge spans, crane booms, lightweight
  frames.
- Fink truss: W-shaped web under pitched rafters; residential and light commercial
  roofs.
- K-truss: panels split into K-shaped shorter webs; deep bridge trusses and large
  industrial frames.

OpenSCAD feature pattern:
```scad
$fn = 48;
span = 160;
rise = 48;
truss_width = 8;
member_width = 6;
member_depth = 6;
gusset_radius = 9;
gusset_thickness = 2;
bolt_diameter = 2.5;

module member_between(p1, p2, w=member_width, d=member_depth) {
  dx = p2[0] - p1[0];
  dz = p2[1] - p1[1];
  L = sqrt(dx*dx + dz*dz);
  a = atan2(dz, dx);
  translate([(p1[0]+p2[0])/2, 0, (p1[1]+p2[1])/2])
    rotate([0, -a, 0])
      cube([L, d, w], center=true);
}

module gusset_at(p) {
  difference() {
    translate([p[0], 0, p[1]])
      cylinder(h=gusset_thickness, r=gusset_radius, center=true);
    translate([p[0], 0, p[1]])
      cylinder(h=gusset_thickness+1, d=bolt_diameter, center=true);
  }
}

module support_pad(x) {
  translate([x, 0, -member_width])
    cube([18, truss_width + 6, 3], center=true);
}

module king_post_truss() {
  left = [-span/2, 0];
  right = [span/2, 0];
  apex = [0, rise];
  mid = [0, 0];
  left_strut_node = [-span/4, rise/2];
  right_strut_node = [span/4, rise/2];
  union() {
    member_between(left, right);
    member_between(left, left_strut_node);
    member_between(left_strut_node, apex);
    member_between(apex, right_strut_node);
    member_between(right_strut_node, right);
    member_between(mid, apex);
    member_between(mid, left_strut_node);
    member_between(mid, right_strut_node);
    for (p=[left, right, apex, mid, left_strut_node, right_strut_node]) gusset_at(p);
    support_pad(-span/2);
    support_pad(span/2);
  }
}

king_post_truss();
```

------------------------

span 160 mm, height 55 mm, 4 bays, chord diameter 6 mm, web diameter 4 mm, joint sphere diameter 8 mm.
Geometry: top and bottom chords are segmented by bay, every bay has a mid-height joint, and four web members form the K pattern into that joint. End verticals and internal center verticals are included.

FINK ROOF TRUSS REFERENCE UPDATE
--------------------------------
Use the node-and-cylinder Fink roof truss model for Fink prompts. It has span 200 mm, rise 70 mm, chord diameter 6 mm, web diameter 4 mm, and joint spheres 8 mm. Geometry nodes are A/B bearings, C ridge, D/E roof midpoints, and F bottom center. Members are bottom chord A-B, rafters A-C and C-B, central web C-F, Fink web D-F/E-F/D-A/E-B, and short ridge braces D-C/C-E.

KING AND QUEEN POST TRUSS REFERENCE UPDATE
------------------------------------------
King-post roof truss primary geometry:
- span = 240 mm, rise = 80 mm, chord_d = 5 mm, web_d = 4 mm, joint_d = 8 mm
- A = left bearing [-span/2,0,0], B = right bearing [span/2,0,0]
- C = ridge [0,0,rise], D = bottom center [0,0,0]
- bottom tie beam: A-D and D-B
- rafters: A-C and C-B
- king post: C-D
- joints are spheres; members are cylinders between 3D points

Queen-post roof truss primary geometry:
- span = 260 mm, rise = 80 mm, chord_d = 5 mm, web_d = 4 mm, joint_d = 8 mm
- A/B are bearings, C is roof peak
- D/E are bottom queen-post points at +/-span/4
- F/G are upper queen-post points at +/-span/4 and rise/2
- bottom tie beam: A-D, D-E, E-B
- rafters: A-C and C-B
- queen posts: D-F and E-G
- straining beam: F-G
- diagonal struts: F-C and G-C
- joints are spheres; members are cylinders between 3D points

REALISTIC I-BEAM REFERENCE UPDATE
---------------------------------
Primary I-beam geometry now uses a 2D rounded steel I-section profile extruded along beam_length:
- beam_length = 220 mm
- height = 55 mm
- flange_width = 42 mm
- flange_thickness = 6 mm
- web_thickness = 7 mm
- inside_fillet = 4 mm at web-to-flange intersections
- edge_radius = 0.8 mm using offset(r) and offset(delta)
- profile contains top flange square, bottom flange square, central web square, and four inside fillet circles
- final beam uses rotate([90,0,0]) and linear_extrude(height = beam_length)
Use this instead of the old three-cube I-beam when the user asks for a realistic long steel I-beam.

NUT TRAP DIMENSIONS (printed pocket)
──────────────────────────────────────
  Add 0.15–0.2 mm to flat-to-flat for printable hex pocket:
  M3 trap: flat_to_flat = 5.7 mm, depth = 2.6 mm  (hex_d = F-F / cos(30°) = 6.58 mm outer circle)
  M4 trap: flat_to_flat = 7.2 mm, depth = 3.4 mm
  M5 trap: flat_to_flat = 8.2 mm, depth = 4.2 mm
  M6 trap: flat_to_flat = 10.2 mm, depth = 5.2 mm
  M8 trap: flat_to_flat = 13.2 mm, depth = 6.7 mm

  // Hex nut pocket module
  module hex_nut_trap(flat_to_flat, nut_height, bolt_d) {
    // nut pocket from below (for side-insertion, rotate 90°)
    cylinder(h=nut_height+0.2, d=flat_to_flat/cos(30), $fn=6);
    // bolt clearance through
    cylinder(h=nut_height+20, d=bolt_d+0.4, $fn=32);
  }

SQUARE NUT TRAPS (often easier to print)
──────────────────────────────────────────
  M3 square nut: 5.5 × 5.5 mm, thickness 2.4 mm  → pocket 5.7 × 5.7 × 2.6 mm
  M4 square nut: 7.0 × 7.0 mm, thickness 3.2 mm  → pocket 7.2 × 7.2 × 3.4 mm
  M5 square nut: 8.0 × 8.0 mm, thickness 4.0 mm  → pocket 8.2 × 8.2 × 4.2 mm

  module square_nut_trap(nut_w, nut_h, bolt_d) {
    cube([nut_w+0.2, nut_w+0.2, nut_h+0.2], center=true);
    cylinder(h=nut_h+20, d=bolt_d+0.4, center=true, $fn=32);
  }

BOLT PATTERN ARRAYS
────────────────────
  // Rectangular 4-hole pattern
  module bolt_pattern_rect(lx, ly, hole_d, depth) {
    for(x=[-lx/2, lx/2]) for(y=[-ly/2, ly/2])
      translate([x, y, 0]) cylinder(h=depth+2, d=hole_d, $fn=32);
  }
  // Circular N-hole pattern
  module bolt_pattern_circle(bolt_circle_d, n_holes, hole_d, depth) {
    for(i=[0:n_holes-1])
      rotate([0,0,360*i/n_holes])
        translate([bolt_circle_d/2, 0, 0])
          cylinder(h=depth+2, d=hole_d, $fn=32);
  }

DESIGN RULES
────────────
  - Side-entry nut traps: orient so nut slides in from side during assembly; depth = nut height + 0.2 mm
  - Bottom nut traps: flat bottom; add 0.5 mm extra depth for imperfect first layers
  - Heat inserts: print hole 0.2–0.4 mm smaller than insert OD; insert while hot, flush with surface
  - Minimum wall around bolt hole: ≥ 1.5 × bolt_diameter from hole edge to part edge
  - For through-bolts: use nut trap on far side OR capture nut with separate cap

OPENSCAD CODE INTERPRETATION
Mechanical meaning to code:
- Fastener features are mostly removed material inside a host part.
- Clearance holes are cylinders subtracted through the part.
- Counterbores are larger shallow cylinders subtracted coaxially with the main hole.
- Countersinks are conical cuts using cylinder(d1=head_d, d2=hole_d).
- Hex nut traps are hexagonal prism voids made by cylinder($fn=6) and subtracted.
- Heat-set insert pockets are cylindrical holes sized near insert outside diameter.
- Captive nut pockets need a side access slot if the nut is inserted from the edge.
- Always include surrounding host material in union() first, then subtract fastener features in difference().

OPENSCAD CODE RULE IMPLEMENTATIONS
Use these patterns to turn fastener and nut-trap rules into OpenSCAD.

Rule: clearance hole removes a cylinder through the part.
OpenSCAD action:
  cylinder(h=part_thickness+2, d=bolt_clearance_diameter, center=true, $fn=48);

Rule: counterbore is a larger shallow coaxial recess.
OpenSCAD action:
  translate([0,0,part_thickness/2-counterbore_depth/2])
    cylinder(h=counterbore_depth+0.2, d=head_diameter+clearance, center=true, $fn=64);

Rule: countersink is a conical recess.
OpenSCAD action:
  translate([0,0,part_thickness/2-countersink_depth/2])
    cylinder(h=countersink_depth, d1=head_diameter, d2=bolt_clearance_diameter, center=true, $fn=64);

Rule: hex nut trap is a six-sided prism void.
OpenSCAD action:
  rotate([0,0,30])
    cylinder(h=nut_thickness+clearance, d=nut_across_corners+clearance, center=true, $fn=6);

Rule: side-entry captive nut slot allows insertion.
OpenSCAD action:
  translate([slot_length/2,0,nut_z])
    cube([slot_length, nut_across_flats+clearance, nut_thickness+clearance], center=true);

FLANGE STANDARDS
─────────────────
  ANSI/ASME B16.5 (imperial):  Class 150, 300, 600, 900, 1500, 2500
  DIN 2573 / EN 1092-1 (metric): PN6, PN10, PN16, PN25, PN40
  JIS B 2210 (Japanese)

  Flange types:
  - Weld neck (WN): long tapered neck, butt-welded to pipe
  - Slip-on (SO): slides over pipe, fillet weld
  - Blind (BL): solid plate, closes pipe end
  - Socket weld (SW): counter-bore, fillet weld inside
  - Threaded: internal or external pipe thread, screws onto pipe
  - Lap joint: loose flange + stub end, for adjustable bolt alignment

HOSE BARB DIMENSIONS
─────────────────────
  For flexible hose / tubing connections:
  Barb OD: slightly larger than hose ID for retention grip
  Hose ID 4 mm  → barb major OD 5.0 mm, minor OD 3.8 mm
  Hose ID 6 mm  → barb major OD 7.5 mm, minor OD 5.5 mm
  Hose ID 8 mm  → barb major OD 9.5 mm, minor OD 7.5 mm
  Hose ID 10 mm → barb major OD 11.5 mm, minor OD 9.5 mm
  Hose ID 12 mm → barb major OD 14.0 mm, minor OD 11.5 mm
  Barb count: 2–3 barbs per fitting; barb spacing = hose_ID × 0.8 mm
  Barb angle: 20–30° lead-in angle, 60–70° retention angle (sharp = more grip)

KEY PARAMETERS
──────────────
  pipe_od               — from standard table
  pipe_id               — pipe_od − 2 × wall
  flange_od             — from standard table

  bolt_circle_d         — from standard table

  bolt_hole_d           — from standard (ø14–22 mm)
  raised_face_od        — pipe_od + 30–40 mm (sealing face)

OPENSCAD STRUCTURE (blind flange)
───────────────────────────────────
  flange_od    = 165;   // DN50 PN16
  flange_t     = 20;
  bolt_circle  = 125;
  n_bolts      = 4;
  bolt_hole_d  = 18.5;  // ø18 clearance
  rf_od        = 90;    // raised face
  rf_h         = 2;
  pipe_bore    = 0;     // blind = no bore

  module blind_flange() {
    difference() {
      union() {
        cylinder(h=flange_t, d=flange_od, $fn=128);
        cylinder(h=flange_t+rf_h, d=rf_od, $fn=128);   // raised face
      }
      // bolt holes
      for(i=[0:n_bolts-1])
        rotate([0,0,360*i/n_bolts + 45])
          translate([bolt_circle/2, 0, -1])
            cylinder(h=flange_t+rf_h+2, d=bolt_hole_d, $fn=32);
    }
  }

PIPE ELBOW (90° and 45°)
─────────────────────────
  centerline_radius = 1.5 × pipe_od  (standard long-radius elbow)
  // model as rotate_extrude of pipe cross-section
  module pipe_elbow_90(pipe_od, pipe_id, cl_r) {
    rotate_extrude(angle=90, $fn=64)
      translate([cl_r, 0, 0])
        difference() {
          circle(d=pipe_od, $fn=64);
          circle(d=pipe_id, $fn=64);
        }
  }

DESIGN RULES
────────────
  - Bolt holes in flanges: offset 22.5° from vertical centreline so bolts don't land on top/bottom
  - Gasket face: Ra ≤ 3.2 μm (machine finish); for printed: smooth with gap-filling primer
  - Raised face: always on both mating flanges; never mix RF with flat-face
  - For 3D printed fluid fittings: use water-tight settings (≥ 4 perimeters, 100% infill, PETG)
  - Hose barb: print barb direction so layers are parallel to pull-off force axis
  - Push-fit fittings: OD of insert = hose_ID − 0.3 mm for light press; add barbs for retention

OPENSCAD CODE INTERPRETATION
Mechanical meaning to code:
- A flange is a bolted plate or disk around a central pipe/shaft opening.
- Main flange disk, raised boss, neck, socket, and gasket face are solid material in union().
- Center bore, bolt holes, internal pipe passage, and gasket grooves are removed material in difference().
- The central bore is coaxial on Z for a round flange.
- Bolt-circle holes are repeated using angle = 360*i/bolt_count and cos()/sin() placement.
- A pipe socket is a larger diameter recess around the central bore, not a separate off-axis hole.
- Hose barbs are repeated tapered rings along the pipe axis.
- Keep bolt holes inside the outer diameter with enough edge distance.

OPENSCAD CODE RULE IMPLEMENTATIONS
Use these patterns to turn flange and pipe-fitting rules into OpenSCAD.

Rule: round flange is a disk with central bore.
OpenSCAD action:
  difference() {
    cylinder(h=flange_thickness, d=flange_outer_diameter, center=true, $fn=128);
    cylinder(h=flange_thickness+2, d=pipe_bore_diameter, center=true, $fn=96);
  }

Rule: bolt circle holes repeat around radius.
OpenSCAD action:
  for (i=[0:bolt_count-1]) {
    angle = 360*i/bolt_count;
    translate([cos(angle)*bolt_circle_diameter/2, sin(angle)*bolt_circle_diameter/2, 0])
      cylinder(h=flange_thickness+2, d=bolt_hole_diameter, center=true, $fn=48);
  }

Rule: raised boss strengthens the pipe opening.
OpenSCAD action:
  cylinder(h=boss_height, d=boss_diameter, center=true, $fn=96);

Rule: gasket groove is a shallow annular recess.
OpenSCAD action:
  difference() {
    cylinder(h=gasket_depth, d=gasket_outer_diameter, center=true, $fn=128);
    cylinder(h=gasket_depth+1, d=gasket_inner_diameter, center=true, $fn=128);
  }

Rule: hose barb is repeated tapered ring along pipe axis.
OpenSCAD action:
  for (z=[0:barb_pitch:barb_length])
    translate([0,0,z]) cylinder(h=barb_width, d1=barb_root_d, d2=barb_tip_d, center=true, $fn=96);

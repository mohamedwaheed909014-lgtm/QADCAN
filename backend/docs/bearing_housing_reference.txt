PART FAMILIES
─────────────
1. Pillow Block (Plummer Block)
   - Flat base with two bolt holes, cylindrical boss on top holding bearing
   - Shaft axis is PARALLEL to mounting surface
   - Used: conveyor shafts, CNC leadscrews, 3D printer Z-axis

2. Flanged Bearing Housing (UCF / UCFL type)
   - Circular or square flange, shaft axis PERPENDICULAR to mounting surface
   - Four bolt holes on flange corners
   - Used: wall-mounted shafts, fan assemblies

3. Take-Up Bearing Housing
   - Slotted base allowing linear adjustment for belt tension
   - Slot length typically 20–40 mm

4. Simple Bore Block (end support)
   - Minimal block with single bore, used as end support for rods/shafts

KEY PARAMETERS
──────────────
  shaft_diameter          — shaft OD; housing bore = shaft_d + 0.3–0.5 mm clearance
  bearing_od              — from table above (e.g. 47 mm for 6204)
  bearing_width           — from table above (e.g. 14 mm for 6204)
  bearing_seat_depth      — = bearing_width + 0.2 mm (light press fit on housing)
  housing_length          — ≥ bearing_width + 2 × wall_thickness
  housing_width           — ≥ bearing_od + 2 × wall_thickness
  housing_height          — boss height above base; typically bearing_od/2 + wall_thickness
  base_thickness          — 5–8 mm for printable; 10–15 mm for cast iron equivalent
  wall_thickness          — 6–10 mm typical for FDM structural parts
  hole_spacing            — bolt hole centre-to-centre; = housing_length − 2 × edge_margin
  bolt_hole_diameter      — M4=4.5, M5=5.5, M6=6.6, M8=8.8 (clearance drill)
  edge_margin             — ≥ 1.5 × bolt_hole_diameter from hole centre to part edge
  counterbore_diameter    — bolt head OD + 1 mm
  counterbore_depth       — bolt head height + 0.5 mm

OPENSCAD STRUCTURE
──────────────────
  shaft_diameter = 20;
  bearing_od = 47;
  bearing_width = 14;
  wall_thickness = 8;
  base_thickness = 6;
  housing_length = 70;
  housing_width = bearing_od + 2*wall_thickness;
  housing_height = bearing_od/2 + wall_thickness;
  hole_spacing = housing_length - 2*edge_margin;
  edge_margin = 10;
  bolt_hole_d = 5.5;

  module pillow_block() {
    difference() {
      union() {
        // base plate
        cube([housing_length, housing_width, base_thickness], center=true);
        // bearing boss
        translate([0, 0, base_thickness/2 + housing_height/2])
          cube([bearing_width + 2*wall_thickness, bearing_od + 2*wall_thickness,
                housing_height], center=true);
      }
      // bearing seat
      translate([0, 0, base_thickness/2])
        rotate([0,90,0])
          cylinder(h=bearing_width+1, d=bearing_od+0.2, center=true, $fn=96);
      // shaft through bore
      rotate([0,90,0])
        cylinder(h=housing_length+2, d=shaft_diameter+0.5, center=true, $fn=96);
      // mounting holes
      for(x=[-hole_spacing/2, hole_spacing/2])
        translate([x, 0, 0])
          cylinder(h=base_thickness+2, d=bolt_hole_d, center=true, $fn=32);
    }
  }

DESIGN RULES
────────────
  - Bearing seat is a HOUSING bore: bearing_od + 0.0 to +0.05 mm (transition/press fit)
  - Shaft bore: shaft_d + 0.3–0.5 mm (running clearance)
  - Minimum wall between bearing seat and exterior: ≥ 4 mm
  - For split/clamp housing (printable): add 1.0–1.5 mm clamp gap, two M3/M4 clamping screws
  - Mounting bolt edge distance: centre of hole ≥ 1.5 × bolt_diameter from any free edge

OPENSCAD CODE INTERPRETATION
Mechanical meaning to code:
- The housing body and mounting base are solid support material, so create them in union().
- The bearing seat, shaft clearance, clamp split, and mounting holes are removed material, so subtract them in difference().
- If the bearing axis is horizontal, rotate the bearing-seat cylinder by 90 degrees so its axis passes through the boss.
- Bearing bore diameter represents the bearing outside diameter plus fit clearance; shaft bore represents shaft clearance through the bearing path.
- Add a raised boss around the bearing seat because it represents radial support and wall thickness.
- Mounting holes pass vertically through the base and must be longer than base_thickness.
- A pillow block should be base cube + circular bearing boss + subtracted bearing bore + subtracted base holes.
- A split bearing clamp should add a slit through the boss and cross screws perpendicular to the slit.

OPENSCAD CODE RULE IMPLEMENTATIONS
Use these patterns to turn bearing-housing rules into OpenSCAD.

Mandatory assembly structure:
  module pillow_block_bearing_housing() {
    difference() {
      union() {
        // ONLY solid material here: base block, raised bearing boss, ribs.
      }
      // ONLY removed material here: bearing seat, shaft bore, mounting holes, clamp slits.
      // Do not place holes or shaft clearance inside union().
    }
  }

Rule: base block supports the bearing housing.
OpenSCAD action:
  cube([base_length, base_width, base_thickness], center=true);

Rule: raised bearing boss carries radial bearing load.
OpenSCAD action:
  translate([0,0,base_thickness/2 + boss_diameter/2])
    rotate([90,0,0])
      cylinder(h=boss_width, d=boss_diameter, center=true, $fn=96);

Rule: bearing seat is a precise cylindrical recess through the boss.
OpenSCAD action:
  // Put this after the union() block, inside difference().
  translate([0,0,base_thickness/2 + boss_diameter/2])
    rotate([90,0,0])
      cylinder(h=boss_width+2, d=bearing_outer_diameter+fit_clearance, center=true, $fn=96);

Rule: shaft clearance follows the bearing axis.
OpenSCAD action:
  // Put this after the union() block, inside difference().
  translate([0,0,base_thickness/2 + boss_diameter/2])
    rotate([90,0,0])
      cylinder(h=boss_width+4, d=shaft_diameter+shaft_clearance, center=true, $fn=96);

Rule: mounting bolts pass through base with edge margin.
OpenSCAD action:
  // Put this after the union() block, inside difference().
  for (x=[-mount_hole_spacing/2, mount_hole_spacing/2])
    translate([x,0,0])
      cylinder(h=base_thickness+2, d=mount_hole_diameter, center=true, $fn=48);

PRINTED THREADS (ISO metric approximation)
───────────────────────────────────────────
  OpenSCAD does not have native threads; approximate with linear_extrude+rotate or polyhedron.
  For functional printed threads, add 0.3–0.4 mm clearance to mating parts.

  ISO thread minor diameter (internal tap drill size):
  M3  : minor ø 2.46 mm  → print at ø 2.5 mm for self-tap; ø 3.2 for clearance
  M4  : minor ø 3.24 mm  → print at ø 3.3 mm for self-tap
  M5  : minor ø 4.02 mm  → print at ø 4.1 mm for self-tap
  M6  : minor ø 4.92 mm  → print at ø 5.0 mm for self-tap
  M8  : minor ø 6.65 mm  → print at ø 6.8 mm for self-tap
  M10 : minor ø 8.38 mm  → print at ø 8.5 mm for self-tap
  M12 : minor ø 10.11 mm → print at ø 10.2 mm for self-tap

  Thread pitch (coarse):
  M3=0.5 mm, M4=0.7 mm, M5=0.8 mm, M6=1.0 mm, M8=1.25 mm, M10=1.5 mm, M12=1.75 mm

KNOB DESIGN (thumbscrew / adjustment knob)
───────────────────────────────────────────
  knob_diameter       — 20–50 mm; larger = more torque
  knob_height         — 10–20 mm
  knurling_tooth_count— 20–40 teeth around circumference
  knurling_depth      — 0.8–1.5 mm
  knurling_angle      — 30–45° for diamond knurl; 0° for straight
  bore_diameter       — M3–M8 threaded insert or through-hole
  skirt_depth         — lower chamfer or straight section: 2–4 mm

  module knurled_knob(d=30, h=15, teeth=30, knurl_depth=1.0, bore_d=3.2) {
    difference() {
      union() {
        // main body
        cylinder(h=h, d=d, $fn=128);
        // knurling teeth (approximated as ridges)
        for(i=[0:teeth-1])
          rotate([0, 0, 360*i/teeth])
            translate([d/2 - knurl_depth/2, 0, h/2])
              cube([knurl_depth, 2*PI*d/teeth*0.3, h], center=true);
      }
      cylinder(h=h+2, d=bore_d, center=false, $fn=32);
    }
  }

SHAFT FEATURES
───────────────
  D-CUT (flat on shaft):
    flat_chord = shaft_d - flat_depth
    flat_depth  — typically 0.5–1.5 mm for ø4–10 mm shafts
    // model as cylinder minus one rectangular cutoff
    difference() {
      cylinder(h=shaft_length, d=shaft_d, $fn=64);
      translate([shaft_d/2 - flat_depth, -shaft_d/2, -1])
        cube([flat_depth+1, shaft_d+2, shaft_length+2]);
    }

  KEYWAY (DIN 6885A):
    shaft_d  key_width  key_height  key_depth_in_shaft
    6–8 mm    2 mm       2 mm        1.0 mm
    8–10 mm   3 mm       3 mm        1.5 mm
    10–12 mm  4 mm       4 mm        2.0 mm
    12–17 mm  5 mm       5 mm        2.5 mm
    17–22 mm  6 mm       6 mm        3.0 mm
    22–30 mm  8 mm       7 mm        3.5 mm
    30–38 mm  10 mm      8 mm        4.0 mm

  LOCKING COLLAR / SHAFT COLLAR:
    bore_d      — shaft_d + 0.05 mm (light sliding)
    collar_od   — bore_d + 8 mm minimum
    collar_width— 8–15 mm
    set_screw_d — M4 for shaft ≤ 15 mm, M5 for ≤ 25 mm
    slit_width  — 1.0–1.5 mm (clamp collar)

  CIRCLIP / SNAP RING GROOVE:
    groove_d    — shaft_d − 2 × groove_depth  (approx: shaft_d × 0.9)
    groove_depth— 1.1–1.3 mm (for DIN 471 external rings)
    groove_width— ring thickness + 0.1 mm
    DIN 471 external snap ring dimensions (selected):
    shaft ø6 : ring ø5.6 × 0.7 mm → groove ø5.6 w=0.7
    shaft ø8 : ring ø7.6 × 0.8 mm → groove ø7.6 w=0.8
    shaft ø10: ring ø9.6 × 0.9 mm
    shaft ø12: ring ø11.5 × 1.0 mm
    shaft ø15: ring ø14.3 × 1.0 mm
    shaft ø20: ring ø19.0 × 1.2 mm

STANDOFFS AND SPACERS
───────────────────────
  Hex standoff M3 × L: OD 5.5 mm (across flats), through bore 3.2 mm; lengths 6–50 mm
  Hex standoff M4 × L: OD 7.0 mm, bore 4.2 mm
  PCB standoff (male-female): one end M3 screw, other M3 nut trap
  Round spacer: OD = bolt_d + 4 mm; bore = bolt_d + 0.2 mm; length = desired gap

  module hex_standoff(flat_to_flat=5.5, bore_d=3.2, length=10) {
    difference() {
      cylinder(h=length, d=flat_to_flat/cos(30), $fn=6);
      cylinder(h=length+2, d=bore_d, center=false, $fn=32);
    }
  }

DESIGN RULES
────────────
  - D-cut bore in hub: print ø = shaft_d + 0.1 mm round, then add flat cutoff at +0.0 to +0.1 mm
  - Keyway in hub: key_width + 0.1 mm slot width, depth = hub key depth + 0.1 mm
  - Printed thread for assembly: add 0.3–0.4 mm to bolt_diameter for loose thread print
  - Self-tapping threads: bore ≈ minor_diameter − 0.1 mm; works well in PETG/ABS, poor in PLA
  - Knurling in OpenSCAD: use for(i=...) rotate() translate() cylinder/cube approximation
  - Standoff height tolerance: ±0.2 mm per 10 mm length for FDM; use brass inserts for precision

OPENSCAD CODE INTERPRETATION
Mechanical meaning to code:
- Knobs, threaded bosses, collars, flats, keyways, and shaft features modify rotational parts.
- Knob body, grip lobes, hub, collar, and flange are solid material in union().
- Central bore, set-screw hole, keyway, D-flat, nut trap, and finger grooves are removed material in difference().
- A knob is usually a cylinder on Z with repeated grip features around circumference.
- Knurling can be approximated by repeated shallow cuts or raised ridges using rotate() loops.
- A D-flat is a planar cube cut across a bore or shaft side.
- A keyway is a rectangular slot along the shaft or bore axis.
- OpenSCAD cannot create real threads easily without libraries; approximate thread with labeled clearance or simple helical visual only if requested.

OPENSCAD CODE RULE IMPLEMENTATIONS
Use these patterns to turn knob, thread, and shaft-feature rules into OpenSCAD.

Rule: knob body is a cylinder around central bore.
OpenSCAD action:
  difference() {
    cylinder(h=knob_height, d=knob_diameter, center=true, $fn=128);
    cylinder(h=knob_height+2, d=bore_diameter+clearance, center=true, $fn=96);
  }

Rule: grip ridges repeat around circumference.
OpenSCAD action:
  for (i=[0:grip_count-1])
    rotate([0,0,360*i/grip_count])
      translate([knob_diameter/2,0,0]) cylinder(h=knob_height, d=grip_ridge_diameter, center=true, $fn=16);

Rule: radial set screw hole points toward shaft bore.
OpenSCAD action:
  translate([knob_diameter/2,0,0]) rotate([0,90,0]) cylinder(h=knob_diameter+2, d=set_screw_diameter, center=true, $fn=48);

Rule: D-flat is a planar cut on a shaft or bore.
OpenSCAD action:
  translate([0,bore_diameter/2-flat_depth/2,0]) cube([bore_diameter+2, flat_depth, knob_height+2], center=true);

Rule: keyway is a rectangular slot along the shaft axis.
OpenSCAD action:
  translate([0,bore_diameter/2,0]) cube([keyway_width, keyway_depth, knob_height+2], center=true);
